Literature works
literature.pankajbhattarai.com.np

Styled to match www.pankajbhattarai.com.np (same colours, fonts and light/dark toggle).
All pages share `css/site.css` and `js/site.js`.

Adding a new piece:
1. Copy an existing page of the same kind (e.g. `Ghumto.html` for a story, `Purano_kagaz.html` for a poem).
2. Change the `<title>`, description/og tags, canonical URL, kicker, title, byline date,
   the text inside `<div class="prose">`, and the `data-href` on the Facebook comments box.
   Use `lang="ne"` on the title and prose for Nepali, `lang="en"` for English.
3. Add an entry to `index.html` under the right section. Move the "Latest" lead if it is the newest.
